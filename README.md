# 🌿 Circuito Terê Verde

Sistema web desenvolvido para divulgação e gerenciamento de atrativos turísticos, trilhas, cachoeiras e eventos da região de Teresópolis - RJ.

## 📋 Descrição

O Circuito Terê Verde tem como objetivo centralizar informações turísticas da região, permitindo que visitantes consultem atrações e eventos, enquanto administradores gerenciam o conteúdo disponibilizado na plataforma.

## 🎯 Objetivos

- Divulgar eventos turísticos;
- Facilitar o acesso às informações da região;
- Gerenciar atrativos turísticos e temporadas;
- Proporcionar uma experiência simples e intuitiva para visitantes.

## 👥 Atores

### Administrador
- Realizar login;
- Cadastrar eventos;
- Editar eventos;
- Excluir eventos;
- Gerenciar temporadas;
- Gerenciar atrativos turísticos.

### Visitante
- Consultar eventos;
- Consultar atrativos turísticos;
- Pesquisar informações.

## ✅ Principais Funcionalidades

- Autenticação de administradores;
- Cadastro e gerenciamento de eventos;
- Cadastro e gerenciamento de temporadas;
- Cadastro de atrativos turísticos;
- Consulta pública de informações turísticas;
- Upload de imagens;
- Busca de eventos e atrativos.
